# canon — 연속성 캐논 (옵시디언 볼트)

이 폴더(상위 `14_웹소설`)를 **옵시디언 볼트로 열면** 위키링크 그래프로 인물·떡밥·타임라인이 보인다.
사람(요한)은 여기서 직접 읽고 고쳐 드리프트를 잡고, 생성기(build-local.mjs)는 같은 파일을 읽고 **정해진 규칙으로만** 쓴다.

## 파일별 쓰기 권한 (드리프트 방지의 핵심)

| 파일 | 분류 | 생성기 권한 |
|---|---|---|
| `canon/timeline.md` | 🔒🔒 절대불변 | **append만** (기존 줄 수정·삭제 금지) |
| `canon/world.md` | 🔒 락드 | **append만** |
| `canon/characters/*.md` | 🔒 락드 | 신규 인물 **create** + `## 변화 로그`에 **append만**. 정체 블록 불변 |
| `canon/threads.md` | 런닝 | 매 화 전체 갱신([열림]→[회수]). 누락은 연속성체크가 감시 |
| `state.md` | 런닝 | 매 화 스냅샷 전체 갱신 |
| `synopsis.md` | 누적 | 화당 1줄 **append만** |

원칙: 락드 파일은 **덮어쓰기 절대 없음, 추가만**. 이게 전언게임(telephone) 드리프트를 구조적으로 막는다.
생성 직후 **연속성 체크 패스**(2차 claude 호출)가 새 화를 timeline·world·인물정체·이전 떡밥과 대조해 하드 모순을 잡는다.

## 옵시디언으로 고치고 싶을 때
- 인물 설정이 틀어졌으면 `characters/<이름>.md` 의 정체 블록을 직접 수정.
- 떡밥을 강제로 정리하려면 `threads.md` 편집(다음 생성이 이걸 읽음).
- 방향을 틀려면 `state.md`의 **다음 화 방향**을 고치거나, 사이트 `/novel` 개입폼을 쓴다.
